# Wedding Assets & Illustrations

Place high-resolution custom illustrations and couple photographs here:
- Couple photographs: `public/images/couple.jpg`
- OG social share image: `public/images/og-wedding.jpg`
- Ceremony illustrations: `public/images/events/` (SVGs or WebP)

The website currently uses high-fidelity procedural SVGs for all wedding motifs, mandap artwork, diya lighting, and ornamental dividers, which look crisp and load instantly on all mobile screens.
